# موقع شركة اللمعة الذهبية

صفحة واحدة تعريفية لـ **شركة اللمعة الذهبية لاستيراد الذهب والمجوهرات م.م** — الأنبار / الفلوجة / النزيزة / السوق العصري.

ملفات ثابتة (HTML + CSS + JS)، بدون سيرفر ولا قاعدة بيانات. تشتغل بفتح `index.html` مباشرة.

```
index.html              الموقع كله — صفحة واحدة
logo.html               دليل العلامة (للاطلاع فقط، مو جزء من الموقع)
assets/logo/            ملفات اللوكو
assets/css/style.css    التصميم
assets/js/site.js       الحركة والتفاعل
assets/js/gallery-data.js  قائمة الصور
images/                 مكان صور المحل
```

## اللوكو

**«الاسم هو اللوكو»** — كلمة «اللمعة» بحروف كوفية هندسية، فوقها شعاع ذهبي، وتحتها خط ذهبي مشدود ثم «الذهبية».

الحروف **محوّلة لمسارات SVG حقيقية** — الموقع ما يعتمد على أي خط منصّب بجهاز الزائر، والشكل يطلع نفسه على كل جهاز ومتصفح وبالطباعة.

```
assets/logo/
├─ wordmark.svg              الأساسي — على خلفية فاتحة
├─ wordmark-on-navy.svg      على خلفية كحلية
├─ wordmark-mono-dark.svg    لون واحد داكن (طباعة)
├─ wordmark-mono-light.svg   لون واحد أبيض
├─ lockup.svg                أفقي + سطر «لاستيراد الذهب والمجوهرات»
├─ lockup-on-navy.svg        أفقي على كحلي (المستخدم بالشريط العلوي)
├─ lockup-mono-dark.svg      أفقي لون واحد
├─ mark.svg                  العلامة المختصرة (حرف ل) بمربع كحلي — الفايكون
├─ mark-light.svg            العلامة بدون خلفية
├─ mark-mono-dark.svg        لون واحد داكن
└─ mark-mono-light.svg       لون واحد أبيض
```

**قواعد الاستخدام**

- الحد الأدنى: الاسم الكامل ٧٤ بكسل عرضاً، والعلامة المختصرة ١٦ بكسل.
- مساحة فارغة حوله بمقدار ارتفاع كلمة «الذهبية» على الأقل.
- على الخلفيات الداكنة استخدم `-on-navy`، وعلى الفاتحة `wordmark.svg`.
- **لا** تمطّه، ولا تضيف ظلال أو حدود، ولا تغيّر ألوانه أو المسافات الداخلية.
- افتح `logo.html` بالمتصفح حتى تشوف كل النسخ والأحجام جنب بعض.

> الحروف مبنية أصلاً على خط **Reem Kufi** (رخصة OFL — مسموح الاستخدام التجاري والتعديل)، ومحوّلة لمسارات، فما عاد يهم إذا الخط منصّب أو لا.

## الصور — الخطوة الوحيدة الناقصة

انسخ صور المحل داخل `images/` بنفس الأسماء المذكورة في [ضع-الصور-هنا.txt](images/ضع-الصور-هنا.txt).

قبل ما تنسخها، الشريط المتحرك يعرض إطارات كحلية فيها حرف الـ«ل» ومكتوب «بانتظار الصورة» — يعني الموقع ما يخرب.

لإضافة صور جديدة أو تغيير ترتيبها: `assets/js/gallery-data.js`.

### سرعة الشريط المتحرك

بملف `index.html` ابحث عن `data-marquee` — السرعة تتحكم بيها من `site.js`:

```js
'<div class="mq" style="--dur:74s">'       // الصف الأول
'<div class="mq mq--rev" style="--dur:92s">' // الصف الثاني (باتجاه معاكس)
```

رقم أكبر = حركة أبطأ.
